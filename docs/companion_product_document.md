# Contextual Communication Companion — Product Document

Product thesis, user journeys, MVP scope and validation plan v1.0

> One-line product Turn everyday moments into communication opportunities for nonspeaking and minimally speaking children — with stable core language, context-relevant vocabulary, adult modelling support and clinician-guided focus.

## 1. Problem

- A full AAC device can be difficult to use meaningfully in fragmented daily life; a child may tap without clear evidence of intentional communication.
- Speech therapy is low-frequency relative to the child’s week, while parents, school and other therapists may use the device inconsistently.
- Parents may not know which words to model in a given moment or what to do when the child does not tap.
- Teams lack a shared, lightweight way to carry one communication goal across real settings.
- Raw device usage does not answer whether a concept is becoming intentional and generalised.
## 2. Positioning

> Not another AAC replacement This is a contextual acquisition/scaffolding layer around a child’s broader communication system. It should coexist with TD Snap/LAMP/other AAC and never trap the child in a smaller proprietary vocabulary.

## 3. Core loop

REAL LIFE SCENE → USEFUL LANGUAGE → ADULT MODELS → CHILD RESPONDS IN ANY CLEAR MODALITY → REAL CONSEQUENCE → EVIDENCE → NEXT OPPORTUNITY

## 4. Primary users

| User | Job to be done |
| --- | --- |
| Parent | Make communication practice fit normal life without becoming a therapist. |
| Child | Have useful language available now and have communication change the environment. |
| Speech therapist | Set a focused plan and see whether it transfers beyond the weekly session. |
| School / support team | Know what to model today without learning a complex new admin system. |

## 5. Parent journey

- Open Audrey’s Day; routine is prepared from a weekday template.
- Select current scene or accept the scheduled suggestion.
- See stable core words + 3–6 scene words; optionally replace visuals with family photos.
- Open How to model when unsure. The coach offers natural opportunities and a 'what if she doesn’t tap?' branch.
- Start Child Mode; no formal lesson is required.
- Optionally log what happened in one tap: independent / modelled / prompted / alternative modality / unclear.
- Review progress later, not during the interaction.
## 6. Child journey

- Enter full-screen Child Mode.
- Core words remain in the same position.
- Scene words reflect the current activity only.
- Tap a word → speech output → adult responds naturally.
- No quizzes, scores, rewards, correction screens or pressure to complete.
## 7. Therapist journey

- Open child profile and set the week’s focus.
- Specify target concept, accepted response modalities, wait time, prompt guidance, target scenes and review date.
- System generates parent-friendly modelling examples for each target scene.
- Review evidence across scenes/partners; continue, simplify or change focus.
- Changes are versioned and visible to the family.
## 8. Modelling Coach

| Question | Product support |
| --- | --- |
| How do I model this word? | Concrete examples in the current scene plus why the opportunity is natural. |
| What if she doesn’t click? | Model once, wait, accept another clear modality, do not repeatedly demand a tap, try again later. |
| What if she taps randomly? | Record as unclear, reduce pressure/complexity, look for repeated context-consistent patterns. |
| What if she uses a gesture? | Treat it as communication; model the symbol alongside it if useful. |
| What if she becomes distressed? | Stop the attempt and protect agency; do not require completion. |
| How long should I wait? | Use therapist-set wait time; personalise only within clinician constraints. |

## 9. MVP scope

| Must have | Not in MVP |
| --- | --- |
| Parent day/scenes; stable core + contextual words | Emotion recognition |
| PCS-ready switchable symbol layer + custom photos | Robot/hardware |
| Child Mode with speech output | Autonomous therapy |
| Deep Modelling Coach | Diagnosis or treatment claims |
| Therapist weekly focus | School SIS/NDIS integrations |
| Simple evidence logging/generalisation | Computer vision inference of intent |

## 10. Prototype screens

| Screen | What must be demonstrated |
| --- | --- |
| Parent Today | Quiet planner, ordered scenes, current scene, focus, Start with Audrey |
| Scene Builder | Add/edit/reorder scene; contextual words; symbol/photo override |
| Child Mode | Fixed core + contextual words; speech; parent hold-to-exit |
| How to Model | Scenario ideas + branching support when child does not tap |
| Therapist Studio | Set focus, modalities, wait time, prompt rules, scenes, review date |
| Progress | Opportunities and response types; generalisation across scenes/partners |
| Team Share | One-screen focus and modelling guidance without dashboard complexity |

## 11. Success metrics

- Parent burden: minutes/week spent configuring and logging.
- Execution: number of natural communication opportunities created without formal therapy sessions.
- Communication evidence: independent vs modelled/prompted/unclear patterns.
- Generalisation: concept appears across scenes and communication partners.
- Adoption: family/team members can use the plan without founder or therapist handholding.
- Do not optimise for raw taps, time-in-app or engagement streaks.
## 12. Audrey-first validation

| Period | Question |
| --- | --- |
| Week 1 | Can the family use scenes naturally without adding admin burden? |
| Week 2 | Does stable core + scene vocabulary reduce obvious random interaction or improve meaningful opportunities? |
| Week 3 | Does a target concept appear in more than one scene? |
| Week 4 | Can another family member follow the modelling guidance without live coaching? |
| Weeks 5–8 | Does the speech therapist find the evidence useful enough to change or continue a focus? |

## 13. Product principles

- The product teaches the adult how to listen, not only the child how to press.
- Communication is not a quiz.
- Stable language + contextual access.
- Professional intent, family execution.
- AI stays behind the experience and produces action, not chat for its own sake.
- Child agency beats engagement metrics.
